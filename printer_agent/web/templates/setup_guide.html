STEP 1

🔌 Connect Your Physical Printer to Computer

Your printer must be connected to the Windows computer located at your shop or counter.

[ Physical Printer (HP/Canon/Epson/Brother) ]   ──( USB Cable or Local Wi-Fi )──   [ Shop Computer / Laptop ]
  • USB Connection: Plug the printer's USB cable into any USB port on your PC.
  • Wi-Fi Connection: Ensure both your PC and the printer are connected to the same shop Wi-Fi network.
  • Power & Paper: Turn on the printer and ensure the paper tray has A4 or required paper sheets.
  • Quick Check: Open Windows Printers & Scanners and make sure your printer is showing as "Ready".
STEP 2

💻 Run the 1-Click Shop Agent on Your PC

The Shop Agent is a lightweight background service that receives incoming customer print jobs and feeds them to your connected printer.

⭐ Option 1: Standalone Windows App (PrinterAgent.exe - Recommended)

Zero Setup / Silent Tray

A clean, standalone Windows application that lives right in your system tray (near the clock). No command prompt windows, silent background printing, and instant Windows desktop toast notifications!

⬇️ Download Windows Launcher (start_{{ shop.shop_id }}_agent.bat)

💡 To compile the full standalone PrinterAgent.exe binary for this shop, simply run build_tray_app.bat in the project folder.

Option 2: Direct Command Line / Python Launcher

Double-click run_shop_agent.bat inside this project folder, or run this command in terminal:

python -m printer_agent.shop_client --server "{{ server_url }}" --shop "{{ shop.shop_id }}" --key "{{ shop.api_key }}"
